# Online Examination Management System (OEMS)

## Project Overview
A web-based system designed to manage online examinations for educational institutions.

## Objectives
- Allow lecturers to create and manage examinations.
- Enable students to take examinations online.
- Support examination scheduling and result management.
- Maintain secure examination records.

## Team
Edutech Team D

## Configuration Management
Jira is used for task tracking, while GitHub is used for version control and collaborative development.
